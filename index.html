화면 페이지 스캐너 v8

아이폰·아이패드로 모니터를 비추면, 화면이 바뀔 때마다 자동으로 찍어 1번부터 번호를 붙이고 PDF로 저장합니다.

대기 변화 0.0% 방향 자동 0장
시작하는 방법
  1. 아이폰이나 아이패드를 거치대에 고정하고 모니터 화면이 다 보이게 맞춥니다.
  2. 카메라 켜기 또는 녹화 영상 불러오기를 누릅니다.
  3. 모니터 화면이 카메라 화면을 꽉 채울수록 글자가 선명합니다. 테두리는 자동으로 맞춰지고, 어긋나면 파란 모서리를 끌어 고칩니다.
  4. 자동 스캔 시작. 화면이 바뀌고 멈추면 한 장씩 찍힙니다.
모서리는 손가락으로 끌어서 조정합니다. 조정한 위치는 다음에도 기억합니다.

이 화면에서는 카메라를 쓸 수 없어요.

방법 1: 아이폰·아이패드 카메라 앱으로 모니터를 동영상 녹화한 뒤 ‘녹화 영상 불러오기’로 넣으면, 화면이 바뀐 지점마다 자동으로 페이지를 뽑아 번호를 붙입니다.

방법 2: 함께 받은 HTML 파일을 https 주소로 올려 Safari에서 열면 실시간 카메라 스캔이 됩니다.

업데이트 내역 v8 · 9월 29일

v8

  1. 키보드·조명이 찍히던 문제 수정 — 가로로 길쭉한 밝은 띠(노트북 키보드, 천장 조명)를 문서로 잘못 잡았어요. 이제 문서·화면 비율(가로:세로 0.38~2.6)이 아니거나 너무 작은 사각형은 버리고, 카메라 화면 가운데를 품은 사각형을 우선합니다.
  2. 문서를 못 찾으면 찍지 않고 기다림 — 전에는 테두리를 못 찾아도 예전 모서리 위치로 찍었어요. 이제 자동 모드에서는 문서를 찾을 때까지 다시 시도합니다(계속 실패하면 6번째에 찍음).
  3. 손에 들고 찍을 때 흔들림 방지 — 폰 움직임 센서로 폰이 0.6초 이상 멈춰야 찍어요. 5장 겹쳐 찍기는 프레임이 어긋나면 평균 대신 가장 선명한 1장을 씁니다. 앞 페이지들보다 확연히 흐리면 버리고 최대 3번 다시 찍습니다.
  4. 선택 삭제 추가 — [선택]을 누르고 지울 페이지를 눌러 체크한 뒤 [선택한 N장 지우기]. [전체 선택]도 있어요. 지우면 번호가 1번부터 다시 매겨집니다.

v7

  1. 자동 테두리가 예전 모서리에 묶이던 문제 수정 — 전에는 찾은 테두리가 이전 파란 모서리 범위를 벗어나면 버리고 옛 모서리로 잘랐어요. 이제 매번 화면 전체에서 새로 찾고, 찾은 위치로 모서리도 갱신합니다.
  2. 테두리가 바깥 여백까지 번지던 버그 수정 — 제목줄을 포함하려고 테두리를 넓히는 단계가 사진 가장자리의 어두운 부분을 모니터 테두리로 착각했어요. 넓히는 범위를 8%로 줄이고, 사진 밖은 보지 않으며, 모니터 베젤 두께가 확인될 때만 넓힙니다.
  3. 테두리 미세 조정 추가 — 네 변을 각각 ±1% 안에서 밝기 경계가 가장 뚜렷한 곳으로 맞추고, 분석 해상도를 480→640px로 올렸어요.
  4. 카메라 켤 때 자동 맞춤 재시도 — 전에는 0.4초 뒤 1번만 시도해서 노출이 안정되기 전이면 실패하고 옛 모서리가 남았어요. 이제 옛 모서리를 지우고 최대 5번(약 5초) 다시 시도하며, 자동 스캔 시작할 때도 한 번 더 맞춥니다.
  5. 잘린 결과 표시 — 찍을 때 초록 선이면 자동으로 찾은 테두리, 주황 선이면 못 찾아서 파란 모서리로 자른 것이에요. 아래 안내 문구에도 표시됩니다.
